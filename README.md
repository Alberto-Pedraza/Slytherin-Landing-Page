
### 🐍 Slytherin - Hackathon Landing Page

¡Bienvenidos a nuestro proyecto de Hackathon! Desarrollamos una **landing page temática de Slytherin** que rinde homenaje a la casa más astuta de Hogwarts y sirve como nuestra carta de presentación técnica. Este sitio fue creado a contrarreloj para demostrar nuestro dominio en el desarrollo web frontend y el trabajo en equipo en Git. 

### 🏆 El Reto del Hackathon

El objetivo principal fue diseñar y construir una página web **atractiva, responsiva y funcional en tiempo récord**, demostrando habilidades sólidas en el uso de herramientas de desarrollo y flujos de trabajo colaborativos en equipo. 

### 🛠️ Hechizos y Tecnologías Demostradas

En este proyecto aplicamos y demostramos conocimientos prácticos en: 

* **HTML5:** Estructura semántica, limpia y accesible para todos los usuarios.
* **CSS3:** Estilos personalizados, gradientes oscuros y detalles plateados que capturan la esencia de las mazmorras.
* **Bootstrap 5:** Sistema de rejilla (*grid*) para un diseño 100% responsivo y componentes rápidos (navbars, tarjetas).
* **JavaScript:** Interactividad, efectos dinámicos al hacer *scroll* y validación de formularios mágicos.
* **Git & GitHub:** Control de versiones estricto, división de tareas por ramas (*branches*) y resolución de conflictos.
* **LocalStorage:** Persistencia de datos para que los artefactos del carrito no se desvanezcan al recargar la página.

### 🏰 Estructura del Proyecto y Desarrolladores

El desarrollo se dividió estratégicamente entre los miembros de la casa: 

### 1. Inicio / Hero Section (Las Mazmorras)

* **Desarrolladores:** Lizbeth, Miguel y Alejandro (también a cargo del Footer).
* **Propósito:** Capturar la atención de inmediato con la mística y elegancia de Slytherin.
* **Elementos:** Navbar funcional, banner principal con fondo oscuro y bordes plata/esmeralda, el lema de la casa y botones de llamada a la acción (CTA).

### 🧪 2. Catálogo Mágico (Tienda de Artefactos)

* **Desarrolladores:** Sofia, Sebastián y Alberto.
* **Propósito:** Mostrar los productos exclusivos que los usuarios pueden adquirir.
* **Elementos:** Filtros dinámicos por categoría (Varitas, Pociones, Indumentaria, Reliquias) y *Bootstrap Cards* con precio en Galeones y botón de "Agregar al Carrito ✨".

### 📜 3. Manifiesto / Sobre Nosotros (La Herencia de Salazar)

* **Desarrollador:** Daniel.
* **Propósito:** Sumergir al usuario en la filosofía de la casa para el modo de "portal de reclutamiento".
* **Contenido:** Bloques informativos sobre las cualidades de un verdadero Slytherin (Ambición, Astucia, Liderazgo).

### 🛒 4. El Carrito de Compras (Gestión de Inventario)

* **Desarrollador:** Eduardo.
* **Propósito:** Desplegar el resumen de los productos seleccionados mediante una ventana modal de Bootstrap.
* **Interactividad:** Modificación de cantidades, cálculo automático en Galeones y botón final de "Finalizar Juramento / Compra".

### ✍️ 5. Formulario de Reclutamiento (El Pacto Esmeralda)

* **Desarrolladores:** Salvador y Alen.
* **Propósito:** Capturar datos del usuario mediante validaciones avanzadas con JavaScript.
* **Campos:** Nombre, Estatus de sangre (toque temático) y confirmación visual interactiva al enviar.

### 🚀 Instalación y Despliegue Local

Si quieres revisar nuestro código y ejecutarlo en tu computadora, sigue estos pasos: 

### 📋 Prerrequisitos

* Tener instalado [Git].

### 💻 Pasos para clonar

1. **Clona este repositorio mágico:** 

bash

git clone https://github.com/Alberto-Pedraza/Slytherin-Landing-Page.git

Usa el código con precaución.
2. **Entra al directorio del proyecto:** 

bash

cd Slytherin-Landing-Page

### ⚡ ¡Lanza el hechizo!

Al estar construido con tecnologías nativas, solo necesitas hacer **doble clic en el archivo index.html** para abrirlo en cualquier navegador web.
